# Ambient-Scene-Scanner

## Key Features Summary:
**Immersive UI:** Full-screen camera feed with a cinematic vignette and a "Design Token" strip that updates in real-time at ~5fps.

**Scene Soul (Vision LLM):** Uses the Gemini 2.5 Flash model to analyze the webcam frame every 6 seconds. It interprets the "vibe" into a witty one-liner and a creative palette name.

**Real-Time Data:** Color extraction is handled in-house using a hidden canvas, segmenting the frame into 5 regions for representative dominant hex codes.

**Polaroid Engine:** A sophisticated canvas-based exporter that replicates the Instax Mini aesthetic, complete with a center-cropped vertical slice, vintage-inspired filters, and typeset metadata (palette name and hex codes).
